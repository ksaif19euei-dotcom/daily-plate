# Daily Plate PWA — GitHub Pages

## Deploy and install

1. Upload the contents of this folder to a static web host that serves files over HTTPS. Keep the files together in the same folder.
2. Open the resulting HTTPS link on your phone.
3. On Android/Chrome, tap **Install app** when it appears, or choose **Install app** from the browser menu. On iPhone/Safari, use **Share → Add to Home Screen**.

Photo guesses use a free image classifier in your browser. The photo stays on your device; the first analysis downloads the model libraries and weights and needs an internet connection. Calorie estimates are rough standard-serving estimates, so confirm the food match and portion before saving.

The app shell works offline after the first visit. Meal entries and photos are stored in that browser on that device; they are not synced between devices.
